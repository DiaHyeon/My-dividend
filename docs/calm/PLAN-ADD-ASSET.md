## กฎเหล็กประจำการพัฒนา (Universal Constraints)
1. **ห้ามแตะต้อง Logic หรือ Calculations**: ฟังก์ชันคำนวณภาษีดอกเบี้ย (`evaluateCashTax`), การค้นหาหุ้น/กองทุน SEC (`searchThaiFunds`, `searchStocks`), การแปลงค่าเงิน USD/THB (`fetchExchangeRate`), และการบันทึกฐานข้อมูล Supabase ต้องคงเดิม 100%
2. **รักษาความปลอดภัยและชนิดข้อมูล**: คง `NUMERIC(15, 4)` สำหรับจำนวนหุ้นและราคาต้นทุน
3. **Keyboard Ergonomics**: คง `KeyboardAvoidingView` และ `ScrollView` ภายใน Modal เพื่อป้องกันคีย์บอร์ดบังช่องกรอก
4. **ทำทีละสเต็ปอย่างเคร่งครัด**: เสนอแผน -> ผู้ใช้อนุมัติ -> ลงมือทำ -> ทดสอบ `tsc` & `npm test` -> Commit -> รายงานผลพร้อมรอคำสั่งต่อไป
