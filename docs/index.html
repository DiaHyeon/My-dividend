นโยบายความเป็นส่วนตัว (Privacy Policy)

แอปพลิเคชัน: My dividend  |  ผู้พัฒนา: DiaHyeon  |  วันที่มีผลบังคับใช้: 30 กันยายน 2026

นโยบายความเป็นส่วนตัวนี้อธิบายถึงวิธีที่แอปพลิเคชัน My dividend ("แอปพลิเคชัน" หรือ "เรา") เก็บรวบรวม ใช้งาน จัดเก็บ และปกป้องข้อมูลของผู้ใช้งาน แอปพลิเคชันนี้ถูกพัฒนาขึ้นเพื่อการศึกษาและการติดตามพอร์ตการลงทุนส่วนบุคคล โดยยึดหลักความโปร่งใสและความเป็นส่วนตัวของผู้ใช้เป็นสำคัญ

1. ข้อมูลที่เราเก็บรวบรวม (Information We Collect)

เราเก็บรวบรวมเฉพาะข้อมูลที่จำเป็นต่อการทำงานของแอปพลิเคชันตามที่ผู้ใช้ยินยอมและป้อนเข้าสู่ระบบด้วยตนเอง:

1.1 ข้อมูลบัญชีผู้ใช้ (Account Information)

  • ที่อยู่อีเมล (Email Address): ใช้สำหรับการลงทะเบียน ยืนยันตัวตน เข้าสู่ระบบ และการกู้คืนรหัสผ่าน
  • รหัสผ่าน (Password): ได้รับการเข้ารหัสความปลอดภัยทางเดียว (One-way Hashing) โดยระบบ Supabase Authentication ฝั่งผู้พัฒนาหรือบุคคลภายนอกไม่สามารถมองเห็นรหัสผ่านจริงของผู้ใช้ได้
  • ชื่อที่ใช้แสดงผล (Display Name): เพื่อแสดงคำทักทายบนหน้าจอหลัก (เป็นไปตามความสมัครใจของผู้ใช้)

1.2 ข้อมูลพอร์ตและการลงทุน (Financial Portfolio Data)

  • รายการสินทรัพย์ที่ผู้ใช้บันทึก (ชื่อย่อหุ้น, กองทุนรวม, บัญชีเงินฝากธนาคาร)
  • ข้อมูลธุรกรรม (จำนวนหุ้น, ราคาต้นทุน, วันที่ทำรายการ, อัตราแลกเปลี่ยน)
  • ข้อมูลการปรับแต่งเงินปันผล และการตั้งค่าเป้าหมายรายได้พาสซีฟประจำเดือน
หมายเหตุ: ข้อมูลเหล่านี้เป็นข้อมูลจำลองหรือบันทึกส่วนบุคคลที่ผู้ใช้ป้อนเอง แอปพลิเคชันไม่มีการเชื่อมต่อกับบัญชีธนาคารหรือบัญชีซื้อขายหลักทรัพย์จริงของผู้ใช้แต่อย่างใด

1.3 ข้อมูลที่จัดเก็บบนอุปกรณ์ (Local Storage / Cache)

  • แคชข้อมูลพอร์ตในเครื่อง (AsyncStorage) เพื่อรองรับการเปิดใช้งานแบบออฟไลน์
  • สถานะการตั้งค่า เช่น โหมดซ่อนตัวเลข (Privacy Mode) และวันที่ซิงก์ราคาล่าสุด

2. ข้อมูลที่เราไม่เก็บรวบรวม (Information We Do NOT Collect)

  • ไม่มีการติดตามตำแหน่ง (No GPS / Location Tracking)
  • ไม่มีการเข้าถึงกล้อง ไมโครโฟน หรือสมุดโทรศัพท์ (No Camera, Microphone, or Contacts Access)
  • ไม่มีการติดตั้ง SDK วิเคราะห์พฤติกรรมหรือโฆษณา (No Google Analytics, Firebase, Sentry, Facebook SDK หรือ AdMob)
  • ไม่มีการเก็บ Advertising ID (AAID)

3. วัตถุประสงค์ในการใช้งานข้อมูล (How We Use Information)

เราใช้ข้อมูลของผู้ใช้เพื่อวัตถุประสงค์ดังต่อไปนี้เท่านั้น:

  • ให้บริการและรักษาความปลอดภัยของระบบบัญชีผู้ใช้ (Authentication)
  • ประมวลผลและแสดงผลภาพรวมพอร์ตการลงทุน การคำนวณภาษี และการคาดการณ์เงินปันผลล่วงหน้า 12 เดือน
  • จัดส่งการแจ้งเตือนวันขึ้นเครื่องหมาย XD ตามปฏิทินที่ผู้ใช้ถือครองสินทรัพย์บนอุปกรณ์

4. การเปิดเผยและการแบ่งปันข้อมูล (Data Sharing & Third Parties)

เราไม่ขาย แลกเปลี่ยน ให้เช่า หรือส่งต่อข้อมูลส่วนบุคคลของผู้ใช้ให้แก่บุคคลที่สามเพื่อการค้าหรือโฆษณาใดๆ ทั้งสิ้น

ข้อมูลจะถูกส่งและจัดเก็บบนโครงสร้างพื้นฐานของผู้ให้บริการคลาวด์ที่ปลอดภัย ได้แก่:

  • Supabase (Supabase Inc.): สำหรับบริการจัดเก็บฐานข้อมูลและระบบยืนยันตัวตน มีการปกป้องข้อมูลด้วยนโยบาย Row Level Security (RLS) เพื่อให้ผู้ใช้แต่ละคนสามารถเข้าถึงได้เฉพาะข้อมูลของตนเองเท่านั้น

5. ความปลอดภัยของข้อมูล (Data Security)

  • ข้อมูลทั้งหมดที่ส่งผ่านเครือข่ายระหว่างแอปพลิเคชันและเซิร์ฟเวอร์ได้รับการเข้ารหัสด้วยโปรโตคอลมาตรฐาน HTTPS / TLS
  • ข้อมูลในฐานข้อมูลถูกแยกสิทธิ์อย่างเด็ดขาดตาม User ID ผ่าน Row Level Security

6. สิทธิ์ของผู้ใช้และการลบข้อมูล (User Rights & Data Deletion)

ผู้ใช้มีสิทธิ์ในการจัดการข้อมูลของตนเองอย่างเต็มที่:

  • การแก้ไขหรือลบรายการ: ผู้ใช้สามารถแก้ไขหรือลบรายการสินทรัพย์และธุรกรรมได้ด้วยตนเองผ่านหน้าแอปพลิเคชันแบบเรียลไทม์
  • การขอลบบัญชีและข้อมูลทั้งหมด (Account & Data Deletion): ผู้ใช้สามารถแจ้งความประสงค์ขอลบบัญชีผู้ใช้และข้อมูลทั้งหมดที่เชื่อมโยงกับบัญชีได้ โดยส่งอีเมลมาที่: mydividend.support@gmail.com พร้อมระบุหัวข้อ "ขอลบบัญชี My dividend" เมื่อได้รับการยืนยัน ระบบจะดำเนินการลบข้อมูลของผู้ใช้ออกจากฐานข้อมูลอย่างถาวร
