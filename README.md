# My dividend

แอปพลิเคชันติดตามพอร์ตการลงทุนและคาดการณ์กระแสเงินสดจากเงินปันผลและดอกเบี้ยล่วงหน้า 12 เดือน (Stocks, Mutual Funds, Cash/Fixed Income) พร้อมระบบแจ้งเตือนวันขึ้นเครื่องหมาย XD

---

## ฟีเจอร์หลัก (Key Features)
- **Multi-Asset Tracking**: ติดตามหุ้นไทย (SET), หุ้นสหรัฐฯ (NYSE/NASDAQ), กองทุนรวมไทย, และเงินฝากธนาคาร
- **12-Month Cashflow Forecast**: คาดการณ์เงินปันผลและดอกเบี้ยสุทธิหลังหักภาษี ณ ที่จ่ายล่วงหน้า 12 เดือน พร้อมไฮไลต์เดือนปัจจุบัน
- **Advance XD Radar & Reminders**: แจ้งเตือนวันขึ้นเครื่องหมาย XD ล่วงหน้าผ่านการแจ้งเตือนบนอุปกรณ์
- **Privacy Mode**: โหมดซ่อนตัวเลขมูลค่าพอร์ตและจำนวนหุ้น สำหรับการเปิดใช้งานในที่สาธารณะ
- **Benchmark Comparison**: เปรียบเทียบผลตอบแทนสะสมของพอร์ตกับดัชนีอ้างอิง (SET, S&P 500, NASDAQ)
- **CSV Portfolio Import/Export**: รองรับการนำเข้าและส่งออกข้อมูลพอร์ตการลงทุนผ่านไฟล์ CSV
