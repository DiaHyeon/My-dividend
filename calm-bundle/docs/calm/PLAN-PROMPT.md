# พรอมต์ขั้น "วางแผน" (อ่านอย่างเดียว ห้ามแก้โค้ด)
ใช้กับโมเดลตัวใดก็ได้ที่อ่านไฟล์ในโปรเจกต์ได้ (Sonnet หรือ Gemini) ให้แยกเป็นแชตใหม่ต่างหากจากแชตที่ลงมือแก้

---
บทบาท: คุณเป็น "ผู้วางแผน" เท่านั้น ห้ามแก้หรือสร้างไฟล์โค้ดใดๆ
อนุญาตให้สร้างได้ไฟล์เดียวคือ docs/calm/PLAN.md

เป้าหมาย: วางแผนปรับ "สไตล์" หน้า Overview ของแอพ My dividend เป็นธีม Calm Mint
ให้ผู้ลงมือ (โมเดลที่ต้องการคำสั่งชัดมาก) ทำตามได้โดยไม่ต้องตัดสินใจเอง
ห้ามแตะ logic, services, queries, state, การคำนวณ

อ่านก่อน (ตามลำดับ)
1. BRIEF.md ทั้งไฟล์ (เน้นข้อ 4.1, 4.2, 4.15, 4.20, 4.21, 5.7)
2. docs/calm/README.md, PROMPT-1-setup.md, PROMPT-2-overview.md, PLAYBOOK-unseen-pages.md
3. calm-kit/src/theme/tokens.ts และ calm-kit/src/components/ui/*
4. design/calm/*.html (ภาพอ้างอิงสไตล์ ข้อมูลเป็นตัวอย่างและละองค์ประกอบจริงบางอย่าง) และสกรีนช็อตใน design/current/
5. โค้ดจริงของ Overview: Dashboard.tsx, HeroNetWorthCard.tsx, UpcomingPaydayRadar.tsx,
   AdjustDividendModal.tsx, AnnualComparisonSheet.tsx, GoalSettingsModal.tsx,
   CategoryBreakdownModal.tsx, App.tsx (แท็บล่างและปุ่ม +) และไฟล์ที่เรนเดอร์กราฟแท่ง 12 เดือน

ผลลัพธ์: เขียน docs/calm/PLAN.md แบ่งเป็นข้อ 2A-2H ตาม PROMPT-2-overview.md โดยแต่ละข้อมี
- ไฟล์ที่ต้องแก้ (ระบุด้วยชื่อ component/function/ตัวแปร ไม่ใช้เลขบรรทัด)
- ตาราง: องค์ประกอบในโค้ดจริง -> ชิ้นส่วนใหม่ พร้อม props
- รายการ "ต้องคงไว้ ห้ามแตะ" (handlers, state, testID, numberOfLines, minHeight, ตัวคำนวณ)
- ส่วนที่ตารางใน PROMPT-2 หาไม่เจอในโค้ด หรือที่โค้ดจริงต่างจาก BRIEF
- ความเสี่ยงพร้อมทางสำรอง
- เกณฑ์ตรวจว่าเสร็จ (เปิดแอพแล้วต้องเห็นอะไร)
และหัวข้อ "ลำดับการแก้ไฟล์ที่ปลอดภัยที่สุด" กับ "ไฟล์ที่ห้ามแก้เด็ดขาด"

ข้อกำหนด
- ห้ามเขียนโค้ดเต็ม เขียนเป็นตารางชี้ตำแหน่งและชื่อ props เท่านั้น
- ถ้าไม่แน่ใจเรื่องไหน ให้เขียนว่า "ไม่แน่ใจ" ห้ามเดา
- ถ้าขาดข้อมูล ให้ถามฉันก่อนเขียนแผน
- เขียนให้ผู้ลงมือที่ไม่เคยเห็นการสนทนานี้อ่านแล้วทำตามได้ทันที
