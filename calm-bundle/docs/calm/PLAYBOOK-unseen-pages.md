# คู่มือสำหรับหน้าที่ยังไม่มีบอร์ดออกแบบ

ใช้กับ: Holdings (มีบอร์ดแล้วแต่ไม่ครบ), Portfolio, Auth, AddAssetModal, EditAssetModal, SellAssetModal,
EditTransactionModal, ImportCsvModal, CalendarPickerModal, SectorPickerModal, CashAssetForm, CategoryBreakdownModal,
OfflineNoticeToast และมุมมองประวัติรายการ

หลักการ: ไม่ต้องมีภาพทุกหน้า ให้จำแนก "ทุกองค์ประกอบ" ลงในกฎ 8 ข้อนี้ ชิ้นไหนไม่เข้ากฎ ให้หยุดและถาม

## กฎ 8 ข้อ (ส่งให้ AI ทุกครั้งที่ทำหน้าใหม่)
1. พื้นหลังหน้า = colors.bg ; พื้นแถบนำทาง/ชีต = colors.surface
2. กล่องสีขาว/การ์ดสว่างทุกใบ = <Card> (variant surface) ; กล่องมืด/เข้ม = <Card variant="dark">
3. ป้าย แท็ก ชิป ตัวกรอง สถานะ ทุกชนิด = <Pill> (เลือก kind ตามตารางด้านล่าง)
4. ปุ่มทุกปุ่ม = <CapsuleButton> (หลัก=ink, รอง=surface, เน้นบนพื้นเข้ม=accent) ; ปุ่มอันตราย (ลบ) = surface + ข้อความ colors.lossOnLight
5. ตัวอักษรทุกชิ้น = <CalmText> (หัวข้อ/ตัวเลขใหญ่=display, ป้ายกำกับ=mono, ข้อความทั่วไป=body) ขนาดไม่ต่ำกว่า 11
6. ช่องกรอก = inputStyle จาก tokens ; label เหนือช่อง = CalmText mono 11 ; ข้อความผิดพลาด = colors.lossOnLight พร้อมไอคอน/สัญลักษณ์
7. modal / bottom sheet = <SheetFrame> ภายใน <Modal> เดิม
8. กราฟ = เปลี่ยนเฉพาะสีผ่าน tokens (chartColors และ colors) ห้ามแตะการคำนวณหรือไลบรารี

## ตาราง Pill
| ความหมายเดิม | kind |
|---|---|
| กำไร / สถานะบวก บนพื้นเข้ม | accent (glyph ▲) |
| ขาดทุน บนพื้นเข้ม | lossDark (glyph ▼) |
| ตัวเลือกที่ถูกเลือก / ปุ่มกรองที่ active | ink |
| ตัวเลือกที่ไม่ถูกเลือก | outline |
| ป้ายบนพื้นเข้ม แบบโปร่ง | outlineDark |
| คาดการณ์ / พิเศษ / ยังไม่ยืนยัน | dashed |
| ป้ายสกุลเงิน (USD $), ประเภท (หุ้น/กองทุน) | outline |

## ตัวเลขกำไร/ขาดทุนทุกจุด
บนพื้นสว่าง: สีจาก trend(v).color ; บนพื้นเข้ม: trend(v, true).color ; ต้องมี glyph ▲/▼ ข้างตัวเลขเสมอ

## ขั้นตอนต่อหน้า (วนซ้ำจนครบ)
1. ส่งสกรีนช็อตหน้านั้นของแอพปัจจุบัน + กฎ 8 ข้อ + ชื่อไฟล์ ให้ AI
2. ให้ AI "ทำรายการ" ก่อนลงมือ: ตารางองค์ประกอบเดิม -> คอมโพเนนต์ใหม่ (เหมือนข้อความ 2A-2H) และรอฉันอนุมัติ
3. อนุมัติแล้วให้แก้ทีละไฟล์ commit ทีละไฟล์
4. เปิดแอพ แคปหน้าจอผลลัพธ์ ส่งให้ Claude (ผู้ออกแบบ) ตรวจเทียบกับระบบดีไซน์ แล้วแก้จุดที่หลุด
5. หน้าสำคัญที่คนเปิดบ่อย (Auth, AddAssetModal) ให้ขอ Claude ออกแบบบอร์ดจากสกรีนช็อตก่อน แล้วค่อยลงโค้ด
